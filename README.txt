COURT DROP v5.5 — Global Tennis Explorer (Mobile)

INSTALL
  Upload index.html to the root of your existing GitHub Pages site.
  courts.json and COURT_SOURCES.csv are optional reference files: the HTML includes
  the full 547-venue library and works on its own. Do not replace your site URL.

WHAT'S NEW
  - Optional once-per-local-calendar-day Tennis Drop + daily streak.
  - Mini missions (discover, save, visit, play in a city), kept inside Badges.
  - Improved rarity reveals and anti-repeat selection.
  - Extra collectible City Collection and Daily Drop PNG share cards.
  - Two new badge achievements: Three-Day Streak, Mission Starter.

WHAT'S PRESERVED
  547 venues in 20 cities (same JSON records), private HK club entries,
  all older passport and full-photo backups, 3 mobile tabs, friend challenge
  links/codes, visit notes, saved and played courts, personal photos, no booking.

DATA SAFETY
  Passport state remains in localStorage as courtdrop_passport_v1;
  visit journal and friend challenge keys are unchanged. New daily drops, missions
  and recent draws use separate v5.5 keys. Export a backup from Settings before
  publishing. New JSON and full backups include daily and mission state.
  Older backups import without deleting v5.5 progress when fields are absent.
  All data is stored in this browser unless exported. Private photos are only
  included in the optional Full Backup (maximum 25 MB uncompressed photos).

LIMITATIONS
  Daily streak uses the browser's local calendar and is not anti-cheat verified.
  Friend challenge progress does not synchronise between devices.
  Venue sources, access restrictions and photos may change. This is a discovery
  game, not a live venue verification system. No reservation or booking data.
